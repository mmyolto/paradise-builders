# Paradise Building Systems — Website

Static multi-page website for Paradise Building Systems Ltd (PBS Civil Works), Port Moresby & Lae, Papua New Guinea.

## Pages
- `index.html` — Home
- `services.html` — Services
- `projects.html` — Projects gallery
- `about.html` — About, values & management team
- `contact.html` — Contact details & quote request

## Structure
- `assets/site.css` — all styles (light & dark mode)
- `assets/site.js` — menu, project filters, lightbox, copy buttons, quote form
- `img/` — logo and project photos

## Publish with GitHub Pages
1. Upload all files and folders to the root of a GitHub repository (keep the folder structure).
2. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, then **Save**.
3. The site will be live at `https://<your-username>.github.io/<repo-name>/` within a few minutes.

## Note on the quote form
The form currently prepares the enquiry text for the visitor to copy and email. To have it send automatically, connect it to a form service (e.g. Formspree) or a mail backend.
